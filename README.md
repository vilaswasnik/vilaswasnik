## Featured projects

### [MrVilsyAgent](https://github.com/vilaswasnik/MrVilsyAgent)
A local-first personal AI agent for Windows (Tauri, React, TypeScript, Rust). Runs local models through Ollama; reads and drafts email but can never send it; indexes your documents with cited answers; tailors resumes with an honest GAP analysis. One design rule throughout: **reads are free, every write waits for your approval.**

### [LinuxGPT-AI-Agent](https://github.com/vilaswasnik/LinuxGPT-AI-Agent)
Plain-English questions in, Linux commands out (Python). GPT-4 reasoning grounded in a bundled commands database, a safety blocklist checked before anything executes, an educational mode that explains the command it used — and a mock mode that runs with no API key at all.

### [Ansible-AI-DevOps-Agent](https://github.com/vilaswasnik/Ansible-AI-DevOps-Agent)
A chat front-end for Ansible (Node.js/Express, OpenAI). Type "get OS details" or "run the services check" and it executes the real playbook and streams the output back. Ships with a family of read-only `check_*` playbooks for logs, network, packages, processes, services, and resources.

## Work with me

I'm looking for three kinds of conversation:

- **Try it / break it** — run a POC of any featured project and tell me where it fails; failure reports with specifics are the most valuable issues in these repos.
- **Contribute** — each featured repo has a CONTRIBUTING.md with concrete good-first-issues (docs, tests, playbooks, database entries — not just code).
- **Discuss** — local-first agents, approval-gated automation, Ansible at scale, AI for Linux operations. If Discussions are enabled on a repo, that's the front door; otherwise open an Issue.

The fastest way to reach me about any of this is a GitHub Issue or Discussion on the relevant repo — I read all of them.
